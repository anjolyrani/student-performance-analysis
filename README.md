
# Student Performance Analysis

## Project Overview
This project analyzes student performance data
using Python and Pandas in Google Colab.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Visualizations
- Bar Chart
- Histogram
- Scatter Plot
- Heatmap
- Line Graph

## Objectives
- Explore student performance data
- Clean missing and duplicate values
- Visualize patterns and correlations
- Understand student performance trends
